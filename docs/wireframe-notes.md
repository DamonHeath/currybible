# Wireframe Notes

## Homepage order

Recommended homepage structure:

1. Hero: clear brand statement and three routes
   - Read Reviews
   - View Rankings
   - Own a Curry House?
2. Trust bar
3. Latest Curry Chronicles
4. Strong owner CTA
5. Rankings preview
6. Curry Map / directory preview
7. Curry Bible Approved affiliate preview
8. Email signup
9. Arcade preview
10. Footer

## Why the owner CTA moved up

The current homepage already has an owner CTA, but it is too far down the page and too small.

The profitable site needs the owner path visible without turning the homepage into a sales page.

The solution is to show it once in the hero buttons and again as a stronger dark-band section after the reviews.

## New navigation

Recommended navigation:

- Home
- Reviews
- Rankings
- Curry Map
- Arcade
- For Curry Houses
- Approved Gear

## Mobile notes

The mobile version must avoid horizontal overflow.

Buttons should stack cleanly.

Review cards should be one column.

The owner CTA must be easy to tap.
